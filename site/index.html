Try the CPU workflow

Clone the source and create a Python 3.11+ environment:

git clone https://github.com/TimeOfAnarchy/vision-bench.git
cd vision-bench
python -m venv .venv

Activate it with .venv\Scripts\Activate.ps1 in Windows PowerShell or source .venv/bin/activate on Linux/macOS, then install:

python -m pip install ".[cpu,demo]"

The offline CPU example generates its own images and a tiny untrained ONNX model. For a packaged installation, download the wheel and checksums from the latest GitHub release.

  • This page distributes the local tool. It does not run inference or use your GPU in the browser.
  • Incomplete source tags remain silver annotations. Unlabeled predictions are not verified false positives.
  • Real GPU and VLM measurements depend on your hardware and runtime. The generated example checks the workflow, not real model quality.
